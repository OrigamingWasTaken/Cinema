# TV Series Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** add TV shows to the Cinema phone app and Infuse. Shows are fetched a season at a time or followed while airing, and episodes play while they download.

**Architecture:**
- Sonarr v5, pinned, finds and imports episodes, and drives our existing rqbit through its native RQBit client.
- The cinema app talks to Sonarr's v3 API. It keeps a polled snapshot that merges Sonarr's queue and episode files with rqbit's per-file progress.
- That snapshot feeds the phone API (Shows tab, show page, Downloads) and a new `/dav/Shows` tree. The tree streams in-progress episodes from rqbit and finished ones from disk, under names that never change.

**Tech Stack:** Python 3.12, FastAPI, httpx, guessit, SQLite (app/); Svelte 5 + Vite (app/web/); Docker Compose; DSM Python 3.8 stdlib only (setup.py).

**Spec:** `docs/superpowers/specs/2026-11-15-tv-series-design.md`

## Global Constraints
- Sonarr image: exactly `lscr.io/linuxserver/sonarr:develop-5.0.0.2941-ls209`. Never use a floating tag.
- Sonarr is reached only through its **v3 API** (`/api/v3/...`, header `X-Api-Key`). Ruling: v3 is the stable, documented API (`src/Sonarr.Api.V3/openapi.json` on Sonarr `develop`), while the RQBit client is configured through it like any download client.
- Seasons and episodes use Sonarr's (TVDB) numbering everywhere. TMDB supplies only search, artwork, overview and the Shows rows. Specials (season 0) are hidden.
- WebDAV layout: `Shows/<library_name(title, year)>/Season NN/<library_name(title, None)> - SNNENN<ext>`. A multi-episode file is `SNNENNa-ENNb`. A path is identical before and after import.
- An in-progress episode is listed once its file has `>= READY_BYTES` (100 MiB, `cinema.webdav.READY_BYTES`) downloaded.
- A stall is no progress for `STALL_SECONDS` (600, `cinema.downloads.STALL_SECONDS`) with 0 live peers.
- "Looking for episodes…" lasts 24 h after a request, then "Couldn't find this season yet".
- Version rules:
  - 1080p preferred, 720p accepted, no upgrades.
  - French-only dubs rejected unless the show's TMDB `original_language == "fr"`.
- Upstream failures return 502 `{"error":"upstream","service":"tmdb"|"sonarr"}`. An unknown TMDB id returns 404 `{"error":"not_found"}`.
- When Sonarr is down, films, `/api/home` and `/dav/Movies` keep working.
- The family never sees release names, codecs, seeders or the word Sonarr.
- Copy is in en and fr. The Svelte app keeps no runtime dependency besides svelte. Never use `{@html}` with API strings.
- Finished show torrents never keep uploading. Imports hardlink, never copy.
- Secrets (the Sonarr and Prowlarr API keys, the TMDB token) are never printed, logged or committed.
- Commit messages are a single title line, with no body and no AI attribution.
- Tests:
  - backend: `cd app && .venv/bin/python -m pytest -q`;
  - setup: `cd /home/marlon/Projects/Cinema && python3 -m unittest discover -s tests -q`;
  - web: `cd app/web && npm run check && npm run build`.
  None of them may need Node, the network or the NAS (web excepted for Node).
- Never touch the NAS or run `deploy.sh`.

## Review Focus
1. **Season packs with extras.** A pack holding samples, `.nfo`s, featurettes or a double episode (`S01E01E02`) must list only confidently matched episodes, the double one once. Test: `test_match_files_pack_with_extras_and_double` (Task 4).
2. **Titles with `:`, `/`, accents or a trailing dot.** These go through `library_name` and NFC, and a PROPFIND with decomposed accents still finds the file. Test: `test_dav_shows_unicode_title` (Task 7).
3. **The import moment.** An episode that is both in the queue and has an imported file is listed once, served from disk, at the same path. Test: `test_snapshot_file_wins_over_queue_same_path` (Task 4).
4. **Info hash case.** Sonarr's `downloadId` may be upper case while rqbit's `info_hash` is lower case, and they must still match. Test: `test_snapshot_matches_uppercase_download_id` (Task 4).
5. **Sonarr down or slow.** `/api/home`, `/api/movies/*` and `/dav/Movies` still answer, and `/dav/Shows` serves the last snapshot. Tests: `test_home_works_when_sonarr_down` (Task 6) and `test_tracker_keeps_last_snapshot_on_error` (Task 4).

- Produces, in store.py:
  - `@dataclass ShowDownload(info_hash: str, torrent_id: int, series_id: int, episode_ids: list[int], status: str, progress_bytes: int, added_at: float, last_progress_at: float, finished_at: float | None)`. `status` is `"downloading" | "finished" | "failed"`, and `episode_ids` is stored as JSON text.
  - `Store.upsert_show_download(d)`, `show_downloads() -> list[ShowDownload]`, `delete_show_download(info_hash)`.
  - `Store.season_requested_at(series_tmdb_id: int, season: int) -> float | None`, `set_season_requested(series_tmdb_id, season, at: float)`, `clear_season_requested(series_tmdb_id, season)`.
- Produces, in shows.py:
  - `@dataclass(frozen=True) EpisodeEntry(series_id: int, show_tmdb_id: int | None, title: str, year: int | None, season: int, episode: int, last_episode: int, size: int, progress_bytes: int, mtime: float, path: Path | None, torrent_id: int | None, file_index: int | None, download_bps: float, eta_s: int | None, state: str)`:
    - `state` is `"preparing" | "ready" | "done" | "failed"`;
    - `path` is set when it is served from disk, and `torrent_id`/`file_index` when it is streamed;
    - properties: `dirname -> library_name(title, year)`, `season_dir -> f"Season {season:02d}"`, and `filename`, where `filename` is the layout in Global Constraints with the extension of the file it comes from.
  - `match_files(files: list[TorrentFile], items: list[QueueItem], *, anime: bool) -> dict[int, list[QueueItem]]`. It maps a file index to the queue items it holds:
    - parse each video, non-sample file's basename with guessit;
    - with no season in the guess and every item in one season, use that season;
    - for anime with no season, match `episode` against `QueueItem.absolute`;
    - a file matches only when every guessed episode is among the items;
    - non-matches are dropped.
  - `class ShowsTracker(store: Store, sonarr: SonarrClient, rqbit: RqbitClient, now: Callable[[], float] = time.time)`:
    - `.entries: list[EpisodeEntry]` is the listed snapshot: on disk, or in progress with `progress >= READY_BYTES`, or finished but not yet imported;
    - `.failed: list[EpisodeEntry]`;
    - `.open_streams: collections.Counter[int]`, keyed by torrent id and maintained by WebDAV;
    - `.ok: bool` is False when the last refresh failed;
    - `async refresh() -> None`;
    - `invalidate(series_id: int)` forces the series' files to be re-read on the next refresh.
  - `async run_shows_poller(tracker: ShowsTracker, interval: float = 5.0) -> None`, with the same loop and error logging as `run_poller`.
- What `refresh()` does:
  1. Fetch the queue, all series and the rqbit torrents. Join a queue `download_id` to an rqbit `info_hash` case-insensitively. Cache `files(torrent_id)` per torrent id, since they never change.
  2. For each matched file:
     - progress is `stats.file_progress[index]`;
     - upsert a `ShowDownload` keyed by hash, with `last_progress_at` updated only when progress grew;
     - if `finished` and the state isn't paused, pause it and set `status="finished"` and `finished_at`;
     - if the state is `live`, live peers are 0 and it has stalled (the same `_stalled` rule as films, using the poller's start time), call `remove_from_queue(first item id, blocklist=True)`, mark it `failed` and add its episodes to `.failed`.
  3. Episode files: re-read `episode_files` and `episodes` for each series that has queue items this cycle, has been invalidated, or was last read 60 s or more ago. A file on disk wins over a queue entry for the same `(series_id, season, episode)`, under an identical filename.
  4. **The finished-torrent rule** (ruling: pause on finish, then delete once imported). A `finished` ShowDownload whose hash is no longer in the queue, whose episodes all have `has_file`, whose `open_streams[torrent_id] == 0`, and with `now - finished_at >= 60`, gets `rqbit.delete(torrent_id)` (which removes the download copy, while the hardlinked library file stays), and its row is deleted. A 404 from rqbit counts as success.
  5. Failed rows are dropped when a queue item covers any of their episodes again, or after 24 h.
  6. If any Sonarr or rqbit call raises, keep the previous `.entries` and `.failed`, set `.ok = False` and log a warning. Never raise out of `refresh()`.

### Task 5: Shows service (season state, show page, actions)

**Files:**
- Modify: `app/cinema/shows.py`, adding the service part.
- Test: `app/tests/test_shows_service.py`

**Interfaces:**
- Consumes: Tasks 2, 3 and 4.
- Produces:
  - `season_state(episodes: list[SonarrEpisode], *, monitored: bool, queued: set[int], requested_at: float | None, now: float) -> dict`. `queued` is a set of episode ids, and an episode counts as aired when `air_date_utc <= now`. It returns `{"number","state","on_tv","total","aired","downloading"}`, where `state` is the first that applies:
    1. `"downloading"` if any episode is queued.
    2. `"upcoming"` if `aired == 0`.
    3. `"done"` if `on_tv == aired`.
    4. `"looking"` if monitored and `requested_at` is within 24 h.
    5. `"not_found"` if monitored.
    6. `"partial"` if `on_tv > 0`.
    7. Otherwise `"none"`.
  - `class ShowsService(store, sonarr, tmdb, tracker, *, shows_dir: str, now=time.time)` with these async methods. Each takes a TMDB id and returns `page(tmdb_id)` after acting:
    - `page(tmdb_id) -> dict`:
      ```
      {"show": {"id","title","year","end_year","overview","poster_path","backdrop_path","airing"},
       "available": bool, "following": bool,
       "seasons": [{**season_state(...), "episodes": [{"number","title","air_date","state"}] | None}]}
      ```
      - A series not yet in Sonarr gets its season rows from `lookup_tvdb` with `state` `"none"` and `"episodes": None`.
      - `available` is False when `tvdb_id` is None or the lookup returns None. `seasons` is then `[]`.
      - `following` means `monitor_new_items == "all"`.
      - Season 0 is dropped.
      - Episode `state` is `"on_tv" | "downloading" | "missing" | "not_aired"`.
    - `get_season(tmdb_id, season)`:
      1. Add the series if it is missing, with profile `"Cinema FR"` if `original_language == "fr"`, else `"Cinema"`, and `series_type` `"anime"` if `ShowInfo.anime`, else `"standard"`.
      2. Monitor the season with `update_series` (its `seasons[n].monitored=True`) and `monitor_episodes` (all its episodes).
      3. Run `season_search`, `set_season_requested(now)`, then `tracker.invalidate`.

      It also serves "Get the rest" and "Try again".
    - `follow(tmdb_id)`: `update_series(monitorNewItems="all")`. If a season is airing (it has both aired and unaired episodes), also `get_season` it. Not airing raises `NotAiringError`.
    - `unfollow(tmdb_id)`: `update_series(monitorNewItems="none")` and nothing else.
    - `remove_season(tmdb_id, season)`:
      1. Unmonitor the season and its episodes, and `delete_episode_files` for its files.
      2. For queue items in that season, `remove_from_queue(id, blocklist=False)`.
      3. `clear_season_requested`, then `tracker.invalidate`.
    - `home() -> dict` returns `{"yours":[ShowCard],"library":[ShowCard],"trending":[ShowCard],"popular":[ShowCard]}`:
      - `yours` is the Sonarr series with a `tmdb_id` that are followed, have a monitored season, or have files;
      - `library` is those with any files;
      - cards come from `tmdb.tv`.
  - `class NotAvailableError(Exception)` (no tvdb id, or the lookup failed) and `class NotAiringError(Exception)`.
  - Per-show `asyncio.Lock` around every action.
